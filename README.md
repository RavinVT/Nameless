# Nameless
A Minecraft PaperMC plugin with some lore about its actions.

## The background
In nameless you play as one of many escaped asylum inmates, you and your comrades shares something in common you can't remember your names only your assigned number.


## Features
 - Players all share the same skin and cape no matter what.
 - Players all have a number instead of a username.
 - Chat is disabled (It just prevents the server from using the chat).
 - When typing on signs occasionally your text shifts.
